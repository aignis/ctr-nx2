# Attribution and data boundary

CTR NX2 is a set of modifications to CTRPad (GPL-3.0), built on CTR Native and CTR-ModSDK. See the links and pinned revision in README.md and the upstream projects' license and attribution notices, including CTRPad's `RIGHTS_AND_LICENSES.md` and vendored third-party notices.

No retail disc image, game executable, game asset, firmware, key, save file, or generated table is included here. Scripts operate on the user's own local data. PAL font tables are generated locally from the supplied PAL disc and must remain outside version control. This repository is not affiliated with or endorsed by the rightsholders.
